1. From Development Project to Live Business System

The Big Picture

Right now, you have source code — a set of instructions that tell a computer how to run the feedback platform. But source code on a laptop is not a working system. To make it available to real customers in real businesses, you need four things:

Step 1: Where Does the Application Live?

The application — the website customers and managers see — must run on a server: a computer that stays on 24/7 and is connected to the internet.

☁️ Cloud Hosting (Recommended)
Vercel, Netlify, Fly.io		 No hardware to buy, auto-scaling, built-in HTTPS, easy rollbacks Monthly cost, requires internet 20–100 KWD Most businesses

🏢 On-Premises Server Data never leaves your building, no monthly fee Buy hardware, handle power/cooling/backups 0 (500–2,000 KWD upfront) Large enterprises with strict data rules
💡 Recommendation: Use Vercel for the frontend and Supabase for the database. Both offer free tiers with easy upgrades. The platform was built specifically for these services.

Step 2: How Is the Database Hosted?

Customer feedback data lives in a PostgreSQL database — like a giant smart spreadsheet that organizes everything into tables.

Data TypeWhere It's StoredHow Long
Customer feedbackDatabaseIndefinitely (until you delete)
Survey questionsDatabaseIndefinitely
User accountsDatabase (auth.users)Until account is deleted
Organization settingsDatabaseUntil organization is deleted
Logos and imagesSupabase Storage bucketUntil deleted
Audit logsDatabaseIndefinitely
📌 Data location: Your data is stored on AWS servers in the region you choose (recommend Europe or Middle East for Kuwait). Supabase automatically backs up daily. Paid plans offer point-in-time recovery.

Step 3: How Does the iPad Access the Application?

The iPad does NOT store the application. It acts like a window into the cloud. Here's the path data travels:

iPad (kiosk mode) ↓ opens Safari browser ↓ loads https://feedback.yourcompany.com/kiosk/salmiya-survey ↓ page is served FROM the cloud server ↓ customer taps answers ON the iPad ↓ data is sent TO the cloud server ↓ stored IN the database ↓ manager sees it ON their computer
✅ Why this matters: If the iPad breaks, feedback data is NOT lost. If you replace the iPad, just open the same URL. Updates happen instantly — no need to touch each iPad.

📱 Any device works

The kiosk page works on any device with a browser — iPad, iPhone, Android tablet, laptop, or desktop. Customers can also access the survey from their own phone via QR code.

Step-by-Step iPad Setup

Step 1: Prepare the iPad

  1. Unbox the iPad and charge it to 100%
  2. Turn it on and connect to your business WiFi
  3. Sign in with an Apple ID (dedicated business Apple ID recommended)
  4. Update to the latest iPadOS version (Settings → General → Software Update)
  5. Disable Auto-Lock: Settings → Display & Brightness → Auto-Lock → Never

Step 2: Configure the Kiosk (Free Method — Guided Access)

  1. Go to Settings → Accessibility → Guided Access
  2. Toggle Guided Access ON
  3. Tap Passcode Settings → Set Guided Access Passcode (4-digit code — write this down!)
  4. Toggle Display Auto-Lock to keep screen on
  5. Open Safari and go to: https://feedback.yourcompany.com/kiosk/[survey-slug]
  6. Triple-click the Home button (or Side button on newer iPads)
  7. Tap Start in the top-right corner

The iPad is now locked into the survey. Customers cannot close Safari, open other apps, or access settings.

Step 3: Physical Installation

  1. Place the iPad into the enclosure
  2. Connect the charging cable and route it through the cable slot
  3. Lock the enclosure with the key
  4. Mount the enclosure at the chosen location
  5. Verify the screen is visible and at a comfortable height
  6. Test: walk up, submit feedback, confirm it works
🔑 Important: Keep the Guided Access passcode and enclosure key in a safe place. Create a shared note in your company password manager. Both employees and managers need to know the passcode for troubleshooting.

4. Network Architecture

Simple Data Flow Diagram

CUSTOMER INTERNET CLOUD │ │ │ ▼ ▼ ▼ ┌──────────┐ ┌────────────┐ ┌───────────────┐ │ iPad │──WiFi──▶ │ Your Router │──Internet──▶│ Vercel │ │ (Kiosk) │ │ (Business) │ │ (App Server) │ └──────────┘ └────────────┘ └───────┬───────┘ │ ▼ ┌──────────┐ ┌────────────┐ ┌───────────────┐ │ Manager's │──WiFi──▶ │ Internet │──Internet──▶│ Supabase │ │ PC/Phone │ │ │ │ (Database) │ └──────────┘ └────────────┘ └───────────────┘

What Happens When a Customer Taps "Submit"?

  1. iPad sends data — The customer's answers are packaged into a secure HTTPS request (like a sealed envelope) containing the answers, survey ID, and fingerprint. (0.1–1 second)
  2. Data travels — The request goes from iPad → WiFi → router → internet → Vercel server. (0.2–1 second)
  3. Server validates — The server checks the survey is active, all required questions are answered, and this isn't a duplicate submission. (0.05–0.2 second)
  4. Database stores — A new row in survey_responses plus rows in survey_answers for each question. (0.05–0.2 second)
  5. Alert check — The database automatically checks if the rating is below the threshold and creates an alert if needed. (0.05 second)
  6. "Thank You" displayed — The server sends back a success response. The iPad shows the thank-you message. (0.1 second)
  7. Kiosk resets — After 3–5 seconds, the kiosk returns to the starting screen for the next customer.
  8. Manager sees it — Next time the manager logs in, the response is visible. If an alert was triggered, it appears in the Alerts section.
⏱️ Total time: From tapping Submit to seeing "Thank You" — 1 to 3 seconds on a typical internet connection.

6. Installation Checklist

Pre-Installation (1–2 Weeks Before)

  • Select hosting provider (Vercel + Supabase)
  • Create accounts with hosting providers
  • Register domain name (e.g., feedback.yourcompany.com)
  • Configure DNS to point domain to hosting provider
  • Purchase iPad(s) and security enclosures
  • Ensure business internet is installed and reliable
  • Test WiFi coverage at kiosk location(s)
  • Create admin accounts in the system
  • Configure survey questions (bilingual — English + Arabic)
  • Generate QR codes and have them printed professionally

Installation Day — Cloud Setup

  • Deploy frontend to Vercel
  • Apply database migrations to Supabase
  • Configure environment variables (API keys, URLs, secrets)
  • Verify domain resolves correctly
  • Test HTTPS (green padlock in browser)
  • Create organization in the platform
  • Set up locations in the platform
  • Create and publish the first survey
  • Invite team members (admin, managers)
  • Test submission through public URL

Installation Day — Kiosk Setup

  • Unbox iPad and charge to 100%
  • Connect to WiFi
  • Update iPadOS to latest version
  • Disable auto-lock (Settings → Display → Auto-Lock → Never)
  • Open kiosk URL in Safari
  • Configure Guided Access (set passcode, start session)
  • Test full submission flow (rate → submit → thank you → auto-reset)
  • Place iPad in enclosure and lock
  • Connect power
  • Final test — walk up as a customer and submit

Installation Day — Manager Setup

  • Train manager on logging in and navigating the dashboard
  • Show manager the responses and alerts sections
  • Verify manager sees only their location's data
  • Test alert workflow (submit low rating → alert created → acknowledge → resolve)

Post-Installation (Week 1)

  • Monitor daily — are responses coming in?
  • Check for errors in server logs
  • Verify backups are active (Supabase does this automatically)
  • Adjust survey if questions are confusing
  • Train employees on assisting customers with the kiosk
  • Create a support contact for when issues arise

7. Staff Training Guide

Your Role With the Feedback System

As a staff member, your main jobs with the feedback system are:

  1. Keep the kiosk working — make sure customers can use it
  2. Help customers who are confused by the kiosk
  3. Keep an eye on feedback — especially negative comments

Starting Your Shift

✓Action
☐Walk past the kiosk. Screen on? Survey showing? If yes → ✅ working.
☐Log into the dashboard (managers). Open browser → go to your company URL → enter email and password.
☐Check for new responses and any alerts (red badges).
☐Mention the kiosk to customers: "If you'd like to tell us about your visit, tap the screen by the exit."

During Your Shift

  • If a customer looks confused near the kiosk, offer help
  • If the screen goes dark, tap it once
  • If the screen is off completely, check the power cable
  • Report any issues to your manager

What to Do If...

The iPad screen is black

1. Tap the screen gently. 2. Check the power cable. 3. Press the Top button once. 4. If still off, hold Top button until Apple logo appears. 5. Wait 1 minute for it to restart. 6. If it comes back, it should show the survey automatically. 7. If not, call the manager.

The survey page is showing an error

1. Triple-click the Home/Side button. 2. Enter the passcode (ask your manager). 3. Tap End. 4. Open Safari. 5. Type the kiosk URL. 6. Triple-click Home/Side → tap Start. 7. Tell the manager what happened.

The internet stops working

1. Place the "Scan on your phone" QR code card on the kiosk stand. 2. Ask customers to scan with their personal phone (uses mobile data). 3. Notify the manager to check the router. 4. Data is not lost — responses will work again when internet returns.

A customer is having trouble

1. Walk over and ask if they need help. 2. Show them: "Just tap the stars, then tap Submit." 3. For Arabic speakers, show them how to switch language. 4. If the screen is not responding, wipe it clean (fingerprints block touch). 5. Hand them a QR code card to use their own phone.

8. Customer Experience Flow

Complete Customer Journey

Step 1: Customer enters the business. They have their meal, shopping, or service. The kiosk is positioned near the exit — visible but not intrusive.

Step 2: Customer notices the kiosk. The screen shows your logo, a friendly message like "How was your experience?" and the location name.

Why this screen exists: A branded, welcoming screen makes customers more likely to participate.

Step 3: Customer selects a rating. Large touch buttons appear: 5 stars (Excellent) down to 1 star (Very Poor).

Why large targets: Quick interaction works even if the customer is in a hurry, has poor eyesight, or shaky hands.

Step 4: Optional follow-up. If rating was positive → "What did you enjoy most?" (Staff, Food, Cleanliness, etc.). If rating was low → "What went wrong?" or "Any suggestions?" with a text box.

Step 5: Thank you. A checkmark or smile appears with "Thank you for your feedback!"

Why this screen exists: The customer should feel heard. A thank-you makes them more likely to give feedback again.

Step 6: Kiosk resets automatically. After 3–5 seconds, the screen returns to Step 2 for the next customer.

9. Maintenance Plan

Daily (2 minutes)

  • Check the kiosk screen is on and showing the survey
  • Wipe the screen with a soft cloth (fingerprints build up)
  • Verify the power cable is connected
  • Check the dashboard for any new alerts

Weekly (10 minutes)

  • Review all feedback from the past week
  • Acknowledge or resolve any open alerts
  • Check that response count seems reasonable for your traffic
  • Clean the kiosk enclosure thoroughly
  • Test a submission from the kiosk yourself
  • Check QR code cards are still in place and not damaged

Monthly (30 minutes)

  • Review surveys — still relevant? Need new questions?
  • Review team access — remove accounts of employees who left
  • Check database storage usage (Supabase dashboard)
  • Test data export (CSV) to verify backups work
  • Review analytics — compare this month to last month
  • Replace any worn or damaged QR code cards

Quarterly (1 hour)

  • Full user audit — review all accounts, locations, and surveys
  • Performance check — is the system responding quickly?
  • Security review — check for unusual login attempts (Supabase logs)
  • Verify SSL certificate is still valid (auto-renewed by Vercel)
  • Check iPad battery health (Settings → Battery → Battery Health)
  • Update iPadOS if a major version is available
  • Review hosting bill — is current plan still appropriate?

Software Updates

When the platform is updated: No action needed on the iPad. The kiosk automatically loads the new version from the server. Updates are deployed by your IT team or system administrator.

10. Scaling to Multiple Locations

From 1 Kiosk to 100 Branches

The system was built from the start to support multi-location, multi-tenant organizations. Here's what changes as you grow:

Database Scaling

StageResponses/MonthPlan

100 branches15,000+Supabase Team + read replicas

Device Management

StageDevicesManagement Strategy
1 kiosk1 iPadGuided Access (free, manual)
5–10 branches5–10 iPadsMDM (Jamf, Scalefusion) — 3–5 KWD/month per device
100 branches100+ iPadsMDM + enterprise deployment (ABM/Apple Business Manager)

What DOESN'T Change When You Scale

  • The customer survey looks the same (customers see no difference)
  • The admin dashboard layout is the same (just more data)
  • QR codes work the same way
  • Each manager sees only their location's data
No code changes needed. The system handles multi-location, multi-tenant data out of the box. You simply add more locations, surveys, users, and iPads through the admin interface.
