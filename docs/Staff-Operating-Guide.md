# Kuwait Feedback Platform — Staff Operating Guide

**Version:** 1.0  
**For:** Front-line staff, shift managers, location supervisors

---

## YOUR ROLE WITH THE KIOSK

The kiosk is a tool for customers to tell us how we're doing. Your job is to keep it working and help customers use it.

**You do NOT need to:**
- Understand how the system works technically
- Fix software problems
- Manage user accounts
- Create surveys

---

## DAILY CHECKLIST

### Start of Shift (2 minutes)

```
START OF SHIFT
☐ Walk past the kiosk
    → Is the screen ON?
    → Is the survey WELCOME screen showing?
    → Is the power cable CONNECTED?

☐ Wipe the screen
    → Use a soft, dry cloth
    → Fingerprints stop the touch from working

☐ Test one tap
    → Tap the "Start Feedback" button
    → Does it respond?

☐ If anything is wrong
    → Tell the shift manager immediately
    → See "What to do if..." below
```

### During Shift

```
DURING SHIFT
☐ Help customers who look confused near the kiosk
    → "Just tap the stars to rate your experience"
    → "It only takes 10 seconds"

☐ If the screen is dark
    → Tap it once (it might be asleep)
    → Check the power cable

☐ If there are fingerprints
    → Wipe the screen with a soft cloth

☀️ EVERY HOUR (optional)
    → Glance at the kiosk — is it still working?
```

### End of Shift

```
END OF SHIFT
☐ Note any issues for the next shift
    → Kiosk was working / not working
    → Any problems with customers using it

☐ If you're the manager:
    → Log into the dashboard
    → Check for new responses today
    → Check for any alerts (negative feedback)
    → Tell the next shift about any important feedback
```

## WHAT TO DO IF...

### The iPad screen is black

**Do this:**
1. Tap the screen gently once
2. If still black, press the **Top button** once
3. If still black, hold the **Top button** for 10 seconds
4. Wait for Apple logo → iPad restarts (~2 minutes)
5. When it comes back, it should show the kiosk again
6. If not → call the manager

### The survey page is not showing

**You might see:**
- A blank screen
- An error message
- The iPad home screen

**Do this:**
1. Triple-click the Home/Side button (quickly, 3 times)
2. Enter the passcode: **7799**
3. Tap **End** in the top-left corner
4. You're now free to use the iPad normally
5. Open **Safari** (blue compass icon)
6. Type the kiosk URL (ask the manager for the link if you don't know it)
7. Wait for the welcome screen to load
8. Triple-click Home/Side button → tap **Start**

### The internet stops working

**Signs:**
- Customer taps Submit but gets an error
- Dashboard won't load on the office computer

**Do this:**
1. Check if other devices have internet (your phone?)
2. If the business WiFi is down:
   - Restart the WiFi router (ask manager)
   - Place the QR code card on the counter
   - "Please scan this with your phone to leave feedback"
   - Customers can use their mobile data
   - It will sync when internet returns

### A customer is confused by the kiosk

**What customers might say:**
| They say | You say |
|----------|---------|
| "What is this?" | "It's a quick survey about your visit" |
| "Do I have to?" | "No, but we'd love your feedback!" |
| "How do I use it?" | "Just tap the stars and follow the prompts" |
| "Is it in Arabic?" | "Tap the Arabic button at the top" |
| "Is it anonymous?" | "Yes, we don't ask for your name" |

### The screen is not responding to touch

**Do this:**
1. Check if the screen is dirty (fingerprints block touch)
2. Wipe it clean with a soft cloth
3. If still not responding, restart the iPad (hold Top button)
4. If still broken → tell the manager → use QR code cards instead

### You submitted feedback but want to flag it

**Do this:**
1. Tell the manager directly
2. Say: "I submitted a test and want you to see it"
3. The manager can find it in the dashboard

### A customer gives a very low rating

**Do this:**
1. Don't react negatively to the customer
2. Thank them for their feedback
3. If they want to discuss it, listen and offer to get a manager
4. Tell your manager after the customer leaves
5. The system already created an alert — the manager will see it

## HELPFUL TIPS

**Tip 1: Screen cleaning**
Fingerprints and grease are the #1 reason kiosks stop working. Clean the screen every shift. Use a dry microfiber cloth. No water, no chemicals.

**Tip 2: Customer placement**
If the kiosk is near the exit, customers see it as they leave. That's the best time to ask for feedback — after they've had the full experience.

**Tip 3: Encourage feedback**
Politely mention the kiosk to customers:
> "If you'd like to share your feedback, there's a quick survey on the iPad by the door."

**Tip 4: Negative feedback is helpful**
Don't take low ratings personally. The system helps the business improve. Every negative rating is a chance to get better.
